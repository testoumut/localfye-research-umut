Localfye - Research Milestone

This is my individual research milestone for our Localfye Capstone project. I explored React, Vite, and npm by building a small demo of our Explore page.

What I Worked On
React: Used useState to handle user interactions.
Vite: Set up the project and ran it locally.
npm: Learned how project dependencies are managed.
Filtering: Added category buttons for cafes, parks, restaurants, and bars.
Location Details: Users can click a place to see its description and Swag Score.
How to Run
Clone this repository.
Install dependencies:
   npm install

Start the development server:
   npm run dev

Open the local URL shown in your terminal.
