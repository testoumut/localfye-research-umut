Localfye - Research Milestone

This is my individual research milestone for our Localfye Capstone project. I explored React, Vite, and npm to get a better understanding of how we could build our app's Explore page.

What I Learned
React: I learned how to use useState to update the page when users interact with it.
Vite: I used Vite to set up the React project and run it locally.
npm: I learned how package.json manages dependencies and why running npm install is important when setting up a project.
Interactivity: I built a simple demo where users can filter sample locations by category and click on a location to see its details and Swag Score.
How to Run
Clone this repository.
Run npm install.
Run npm run dev.
Open the local URL shown in the terminal.
