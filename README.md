# Localfye - Research Milestone

This repository contains my personal research milestone for the Capstone project. I chose to explore **React + Vite** for the frontend architecture, utilizing **npm** as the package manager.

## What I Learned
1. **Platform/Framework:** React provides an efficient way to manage state (using `useState`) which is perfect for our map filtering and location selection features. Vite makes the build process incredibly fast compared to Create React App.
2. **Package Manager (npm):** I learned that `package.json` tracks dependencies, while `package-lock.json` ensures deterministic installs across the team. Running `npm install` is crucial before starting any pulled code.
3. **Interactivity:** I built a mini-version of our "Explore" page where users can filter "Hidden Gems" by category and view their "Swag Scores".

## How to Run
1. Clone this repo.
2. Run `npm install` to download dependencies.
3. Run `npm run dev` to start the local server.
